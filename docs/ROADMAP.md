# Roadmap

This is a proposal, not a promise of shipped functionality.

## v0.1: release-to-campaign drafts

- [x] GitHub release and offline JSON input
- [x] Release-note evidence register
- [x] Blog, LinkedIn, Bluesky and newsletter drafts
- [x] Ollama suggestions as a separate unverified artifact
- [x] CLI and automated tests
- [x] Example GitHub Action pipeline that creates a review PR
- [ ] Installable, documented npm package release

## v0.2: repeatable automation

- [ ] Native GitHub App and webhook signature verification
- [ ] Scheduled campaign workflows and durable execution status
- [ ] Customizable templates and contribution-friendly plugin SDK
- [ ] Release diff and linked PR evidence with independent verification
- [ ] Markdown lint and claims-review UI

## v0.3: authorized distribution and feedback

- [ ] Bluesky publisher gated by explicit approval
- [ ] Optional Postiz integration for approved scheduling
- [ ] UTM link generation and privacy-conscious first-party analytics
- [ ] Audit trail, revision history and deduplication
- [ ] Multi-project self-hosted dashboard

## Longer term

- [ ] Community opportunity research using authorized sources
- [ ] SEO and documentation improvement PRs
- [ ] Demo generation and accessibility review
- [ ] Provider-neutral automation workflows with human oversight
