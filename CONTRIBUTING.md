# Contributing to Launch OS

Thanks for helping make technical launches more accessible.

## Developer setup

- Install Node.js 20 or newer.
- Run npm test and npm run check.
- Run npm run demo to generate an offline example into .tmp/demo.
- Open a small issue or pull request describing behavior and its tests.

## Principles

1. Attribution before generation. Never claim facts the release notes do not support.
2. Human approval before publishing or community participation.
3. Local-first operation and no required paid services.
4. Avoid mass unsolicited posting, scraping around access controls, fake engagement, or credential leakage.
5. Prefer small source, model, and publisher adapters over coupling the core to a vendor.

For substantial changes, discuss the workflow and trust boundary in an issue first.
